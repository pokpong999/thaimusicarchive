── ② ระบบแจ้งเตือน (ใหม่) ───────────────────────────────────────
sql/07_notifications.sql ทำงานด้วย trigger ในฐานข้อมูล
จึงแจ้งเตือนเสมอ ไม่ว่าข้อมูลจะเข้ามาทางเว็บหรือทาง SQL ตรง

  แจ้งแอดมินทุกคนทันที เมื่อมีของใหม่รออนุมัติ:
     เพลงใหม่ · ทางเครื่อง · วิดีโอเพลง · ไฟล์เสียง · ไฟล์โน้ต PDF · บันทึกจดหมายเหตุ
     กดที่แจ้งเตือน → ไปหน้า /admin ทันที
  แจ้งสมาชิก เมื่อผลงานของเขาได้รับอนุมัติ → ไปหน้า /dashboard
  แจ้งเจ้าของเรื่อง เมื่อมีคนมาแสดงความคิดเห็น → ไปหน้านั้นเลย
  แจ้งแอดมิน เมื่อมีความคิดเห็นใหม่ (ไว้ดูแลเนื้อหา)

  ไม่แจ้งซ้ำ: คนที่ลงมือเองจะไม่ได้รับแจ้งเตือนการกระทำของตัวเอง
  ไม่ล้ม: ทุก trigger มีตัวดักข้อผิดพลาด ต่อให้แจ้งเตือนพัง การบันทึกข้อมูลไม่ล้มตาม

  components/NotificationBell.js เขียนใหม่
     • เดิมดึงและมาร์คอ่าน "ทุกแถวในตาราง" ไม่กรอง user_id เลย
       (ถ้า RLS ไม่รัด = เห็นและแก้แจ้งเตือนของคนอื่นได้) — แก้แล้ว
     • เด้งทันทีแบบ realtime ไม่ต้องรอ 60 วินาที
     • บอกเวลา "5 นาทีที่แล้ว" · ไอคอนแยกประเภท · ปุ่มล้างที่อ่านแล้ว

  ผลทดสอบบน PostgreSQL จริง (4 สถานการณ์ ถูกต้องทั้งหมด):
     สมาชิกส่งบันทึก      → แอดมินได้รับแจ้ง ✓
     แอดมินกดอนุมัติ      → สมาชิกได้รับแจ้ง ✓
     แอดมินคอมเมนต์       → เจ้าของเรื่องได้รับแจ้ง แอดมินไม่แจ้งตัวเอง ✓
     เจ้าของคอมเมนต์เอง   → ไม่แจ้งตัวเอง แอดมินได้รับแจ้ง ✓
     รันสคริปต์ซ้ำ        → ไม่มี error ✓
