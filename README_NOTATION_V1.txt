ลำดับติดตั้ง (ทำตามลำดับ)
  1. Supabase → SQL Editor → รัน sql/01 แล้วรัน sql/02
     (ในไฟล์ 02 หัวข้อ 0 มีคำสั่งดู policy เดิม — ดูก่อนก็ได้)
  2. GitHub → ลาก lib + components + app ทับ → Commit
  3. รอ Vercel build เสร็จ → Ctrl+F5
  4. ทดสอบตามรายการด้านล่าง

ทดสอบหลังติดตั้ง
  □ /songs/new — พิมพ์ a s d f แล้วเห็นโน้ตขึ้นในตาราง มีเสียง กด "ส่งเพลง" ได้
  □ /admin แท็บ "เพลงใหม่" — เห็นรายการ + บรรทัด "กระสวน: …" ใต้โน้ต → ใส่ Song ID → Approve
  □ เปิดเพลงที่เพิ่งอนุมัติ → แท็บโน้ต → โน้ตขึ้น ท่อนขึ้น (ถ้าใส่ไว้)
  □ ในฐานะแอดมิน: หน้าเพลงใดก็ได้ → แท็บโน้ต → ปุ่ม "✎ แก้โน้ตทางนี้" → แก้ → บันทึก → กลับมาดูเห็นที่แก้
  □ ในฐานะสมาชิกธรรมดา: เพลงของคนอื่น → ไม่เห็นปุ่มแก้ · เห็นเฉพาะ "เสนอทางเครื่องอื่น"
  □ ในฐานะสมาชิกธรรมดา: ลองยิงตรง (ถ้าอยากเช็ค RLS) — update song_melody ของคนอื่นต้องได้ 0 rows
  □ /admin แท็บ "ทางเครื่อง" → Approve → ทางนั้นขึ้นในหน้าเพลงจริง (เดิมกด Approve แล้วไม่เคยขึ้น — แก้แล้ว)

สิ่งที่เปลี่ยนใต้ดิน
  • กฎสะบัด/สองมือมีที่เดียว: lib/notation-core.js → buildVoices() ทั้งกระดานและเครื่องเล่นเรียกตัวเดียวกัน
  • ช่องไฟสะบัดค่าปริยายเป็น 80 ms ทั้งเว็บแล้ว (dropdown ในเครื่องเล่นยังปรับได้ 40–120)
  • song_melody ได้คอลัมน์ section / line_no / krasuan / luktok — ข้อมูลเก่าที่ไม่มี line_no จะจัดบรรทัดละ 2 วรรคอัตโนมัติ
  • approveTang เดิมแค่ติดธง approved ใน melody_submissions ไม่ได้แตกโน้ตลง song_melody → ทางที่สมาชิกส่งไม่เคยขึ้นหน้าเพลง
    ตอนนี้แตกลงจริง + ให้แต้ม 10 + ถ้าเพลงมีทางนั้นอยู่แล้วจะถามก่อนแทนที่

ข้อจำกัดของรุ่นนี้ (ทำต่อรุ่นหน้า)
  • กระดานยังใช้เสียงสังเคราะห์ ยังไม่ต่อ sampler ฆ้องจริง / หน้าทับกลอง / โน้ตสากล (ของเดิมยังอยู่ในหน้าเพลงตามปกติ)
  • ยังไม่มีบันทึกร่างอัตโนมัติ — ถ้าปิดแท็บก่อนกดส่ง ระบบจะถามยืนยันก่อน แต่ไม่เก็บร่างไว้ให้
  • หน้าอนุมัติของแอดมินแสดงกระสวนเป็นข้อความ ยังไม่แสดงเป็นกระดาน
