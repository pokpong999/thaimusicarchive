  (เพิ่มคอลัมน์ level กับ ching ใน song_melody — รันใน Supabase SQL Editor เหมือนเคย)

สิ่งที่เปลี่ยน (ตามที่ Pk สั่ง)
  1. วรรคท้า + วรรครับ — เลิกใช้ตัวเลือก "วรรคละ/บรรทัดละ" ที่งง
     ใส่เลข วรรคท้า __ ห้อง + วรรครับ __ ห้อง แล้วกด "＋ ขึ้นบรรทัดใหม่"
     เช่น 4+4 = บรรทัด 8 ห้องสองวรรค · 4+3 = บรรทัด 7 ห้อง (แบบมุล่ง/ฉิ่งตัด) · วรรครับเลือก "ไม่มี" = บรรทัดวรรคเดียว
     บรรทัดใหม่แทรกต่อจากบรรทัดที่เคอร์เซอร์อยู่ · การตั้งค่านี้มีผลกับบรรทัดที่กดเพิ่มเท่านั้น ของเดิมไม่ถูกจัดใหม่
     ป้ายลูกตกท้ายบรรทัดแสดง "ลูกตก ท้า X · รับ Y" ตามชื่อเรียกใหม่
  2. ตำแหน่งฉิ่ง–ฉับที่ถูกต้อง
     สามชั้น: ฉิ่งท้ายห้อง 4 · ฉับท้ายห้อง 8
     สองชั้น: ฉิ่งท้ายห้อง 2 · ฉับท้ายห้อง 4
     ชั้นเดียว: ฉิ่งขีดที่ 2 · ฉับขีดที่ 4 ของทุกห้อง (เดิมผิด — แก้ทั้งกระดานและเครื่องเล่นหน้าเพลง lib/nathab.js)
  3. อัตราชั้นกำหนดต่อท่อน (เพลงเถา)
     select "อัตรา" ย้ายไปอยู่ที่หัวท่อนแต่ละท่อน — ท่อนสามชั้น/สองชั้น/ชั้นเดียวในเพลงเดียวกันได้
     ฉิ่งและหน้าทับกลองเดินตามอัตราของท่อนนั้น และนับจังหวะตั้งต้นใหม่ทุกต้นท่อน
     ค่านี้เก็บลงฐาน (คอลัมน์ level) เครื่องเล่นหน้าเพลงก็ตีฉิ่งตามอัตราของท่อนโดยอัตโนมัติ
  4. ฉิ่งกำหนดเอง (เพลงจังหวะพิเศษ)
     เลือก "กำหนดฉิ่งเอง (จังหวะพิเศษ)" แล้วคลิกที่แถวฉิ่งเหนือโน้ตได้เลย: ว่าง → ฉิ่ง → ฉับ → ว่าง
     เก็บลงฐาน (คอลัมน์ ching) เครื่องเล่นหน้าเพลงเล่นตามที่กำหนด
